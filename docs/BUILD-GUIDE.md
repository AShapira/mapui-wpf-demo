# 01 — Understand the architecture and prepare the workstation

## Purpose and prerequisites

Build a GIS desktop client whose first successful run needs no server. You need basic C#, a supported Windows x64 workstation (Windows 11 recommended), a .NET 10 SDK from your internal software channel, and read access to your internal NuGet v3 feed. An editor is optional; Visual Studio with .NET desktop development is convenient. WSL can hold source and run core tests, but cannot execute WPF.

The original brief named GeoServer and PostGIS. In this client tutorial, those are possible infrastructure behind the OGC endpoint, not client dependencies. The application never assumes a GeoServer workspace URL convention or opens a PostGIS connection.

## Architecture

```text
WPF controls → MainViewModel → local feature services / OGC adapters
                    ↓                         ↓
                 Mapsui map           bounded HTTP transport
                    ↓                         ↓
          Skia rendering + NTS       existing WMS / WMTS / WFS
```

WPF supplies the window, binding, controls, and dispatcher. Mapsui draws maps and handles navigation. NetTopologySuite represents vector geometry. BruTile reads WMTS matrix definitions and forms tile URLs. MVVM separates the view from commands and state. Dependency injection creates the same configured services once per application lifetime.

WMS returns a georeferenced image for an extent; WMTS returns prearranged tiles; WFS returns feature geometry and attributes. These three protocols solve different problems and cannot be substituted merely by changing a URL.

## Step by step

1. Place the source in a Windows-local directory, for example `C:\dev\mapui-wpf-demo`. Avoid building simultaneously from Windows and WSL into the same `obj` directory.
2. Open Windows PowerShell in that directory.
3. Check tooling:

```powershell
dotnet --info
dotnet --list-sdks
dotnet --list-runtimes
```

4. Confirm an SDK in the 10.0 family is available. `global.json` starts at 10.0.100 and allows later stable feature bands. The runtime-only installation cannot compile the solution.
5. Read `OgcDemo.slnx`. It contains Core, Wpf, Tests, and ManualBuilder. Core uses `net10.0`; Wpf uses `net10.0-windows10.0.19041.0` and `win-x64`. The explicit Windows target selects the modern SkiaSharp WPF assets.

## How to use the lessons

The reference-first path is to build the complete solution in lesson 02, then study and exercise one subsystem per lesson. Each lesson includes the complete files it explains. Files later in the series are dependencies of the complete application, so the lessons are not independent partial-project snapshots.

For reconstruction from a single Markdown document, create directories matching the source headings and save **all** source/configuration listings before the first full build. The final appendix includes tests, scripts, and lock files. Do not copy generated `bin` or `obj` directories between operating systems.

## Checkpoint and failure diagnosis

Success means `dotnet --info` identifies Windows x64 and a .NET 10 SDK. If SDK resolution fails, use an approved SDK matching `global.json`; do not remove the framework requirement. If you only have WSL, continue reading and run core tests there, but leave desktop verification explicitly pending.

# 02 — Restore, build, and launch

## Purpose and prerequisites

Turn the source into a running desktop application using only internal package infrastructure. Complete lesson 01 and obtain your organization's Artifactory NuGet v3 endpoint. The checked-in URL is intentionally unusable until configured.

## Step by step (Windows PowerShell)

1. Make the private feed configuration:

```powershell
Copy-Item NuGet.Config NuGet.local.Config
notepad NuGet.local.Config
```

Replace the `example.invalid` URL. Preserve `<clear />` so NuGet cannot inherit a public source. If authentication is required, use the organization's credential provider; see the configuration reference. Do not add credentials to the tracked template.

2. Restore with the checked-in lock files:

```powershell
dotnet restore OgcDemo.slnx --configfile NuGet.local.Config --locked-mode
```

The lock files pin transitive packages as well as direct references. A missing package in Artifactory is a feed preparation problem, not a reason to turn on public fallback. A content-hash mismatch should be investigated rather than bypassed.

3. Build and launch without triggering another restore:

```powershell
dotnet build OgcDemo.slnx --no-restore
dotnet run --project src/OgcDemo.Wpf --no-build --no-restore
```

4. Look for the blue application header, two local layers, synthetic geometries, and the feature-details panel. The absence of a public basemap is intentional: the neutral background proves that local content works independently of network services.
5. Run the tests after closing the app:

```powershell
dotnet test tests/OgcDemo.Tests --no-restore
```

## Recreating the skeleton in an empty directory

The equivalent starting commands below show how the solution is assembled. Run them only in a **new empty directory**, then replace the generated files with the complete listings from this guide; do not overwrite the supplied reference project with templates.

```powershell
dotnet new sln -n OgcDemo --format slnx
dotnet new classlib -n OgcDemo.Core -o src/OgcDemo.Core -f net10.0 --no-restore
dotnet new wpf -n OgcDemo.Wpf -o src/OgcDemo.Wpf -f net10.0 --no-restore
dotnet sln OgcDemo.slnx add src/OgcDemo.Core src/OgcDemo.Wpf
dotnet add src/OgcDemo.Wpf reference src/OgcDemo.Core
```

The complete source includes the remaining test/tool projects. The supplied project files, not unversioned `dotnet add package` commands, establish the dependency versions.

## Checkpoint

Build succeeds, the local demo opens, and no OGC endpoint is contacted until you explicitly connect a configured service. NU1701 warnings about SkiaSharp indicate an incorrect Windows target version; preserve the complete WPF project file. WPF cannot be launched with Linux `dotnet`, even when cross-compilation succeeds.

# 03 — Compose the application with MVVM, DI, and logging

## Purpose and prerequisites

Understand who owns configuration, state, and lifecycle. Begin with a successful local run from lesson 02. The complete App, view-model, and window files below show the actual wiring; later lessons explain individual commands and adapters.

## Step by step

1. Read `App.xaml`. There is no `StartupUri`: the dependency-injection container constructs the main window.
2. In `App.xaml.cs`, follow startup: create a host rooted at the executable directory, clear inherited configuration sources, read base JSON plus optional local JSON, register options and the singleton view model/window, then show the window.
3. Read `MainWindow.xaml`. Buttons bind to commands generated by CommunityToolkit.Mvvm. Text fields bind to observable state. The map control itself is assigned by the small code-behind adapter.
4. Read `MainViewModel`. It owns the map and layer collection, and exposes commands such as Home, OpenGeoJson, Connect, and Refresh. Network work uses `await`; map/layer mutations resume on the WPF dispatcher.
5. Observe how closing the window cancels active work and disposes the map and transports. A background continuation must not update a closed application.
6. Open the daily log after running the application:

```powershell
Get-ChildItem "$env:LOCALAPPDATA\OgcDemo\logs"
Get-Content (Get-ChildItem "$env:LOCALAPPDATA\OgcDemo\logs\*.log" | Sort-Object LastWriteTime | Select-Object -Last 1).FullName
```

The log records authored events and exception type names, not service URLs, passwords, server bodies, or selected attributes. Mapsui diagnostics are routed through the same policy. This is a small teaching sink; production logging needs an explicit retention policy.

## Why the view adapter exists

Map taps contain screen/world positions and a renderer-provided hit-test function. Converting that UI event into `SelectAsync` belongs at the view boundary. The view model handles selection state and remote identification. Tree selection similarly assigns the selected layer without embedding GIS operations in XAML code-behind.

Commands generated from `async Task` disable concurrent execution of that command. WFS refresh can also be triggered by navigation, so it has its own cancellation and generation guard; command disabling alone is insufficient.

## Checkpoint

Changing observable status updates the status bar; selecting a feature updates the details panel. Launching from a different working directory still finds configuration beside the executable. Closing the window ends the demo process. If startup fails, inspect the documented prerequisites and JSON syntax; the application deliberately does not reveal arbitrary exception payloads in its normal error dialog.

using System.IO;
using System.Windows;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using OgcDemo.Core;

namespace OgcDemo.Wpf;

public partial class App : Application
{
    private IHost? _host;
    protected override async void OnStartup(StartupEventArgs e)
    {
        base.OnStartup(e);
        try
        {
            var builder = Host.CreateApplicationBuilder(new HostApplicationBuilderSettings { ContentRootPath = AppContext.BaseDirectory, Args = [] });
            builder.Configuration.Sources.Clear();
            builder.Configuration.AddJsonFile(Path.Combine(AppContext.BaseDirectory, "appsettings.json"), false)
                .AddJsonFile(Path.Combine(AppContext.BaseDirectory, "appsettings.local.json"), true);
            var options = builder.Configuration.GetSection("Demo").Get<DemoOptions>() ?? new DemoOptions();
            builder.Services.AddSingleton(options);
            builder.Logging.ClearProviders();
            builder.Logging.AddProvider(new FileLoggerProvider(Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "OgcDemo", "logs")));
            builder.Services.AddSingleton<MainViewModel>(); builder.Services.AddSingleton<MainWindow>();
            _host = builder.Build(); await _host.StartAsync();
            var logger = _host.Services.GetRequiredService<ILogger<App>>();
            Mapsui.Logging.Logger.LogDelegate = (level, _, exception) =>
            {
                if (level is Mapsui.Logging.LogLevel.Error or Mapsui.Logging.LogLevel.Warning)
                    logger.LogWarning("Mapsui event; severity {Severity}, exception type {ExceptionType}", level, exception?.GetType().Name ?? "none");
            };
            MainWindow = _host.Services.GetRequiredService<MainWindow>(); MainWindow.Show();
            if (e.Args.Length == 2 && e.Args[0] == "--smoke-test")
                await DesktopSmoke.RunAsync((MainWindow)MainWindow, _host.Services.GetRequiredService<MainViewModel>(), e.Args[1]);
        }
        catch (Exception ex)
        {
            if (e.Args.Length == 2 && e.Args[0] == "--smoke-test")
            {
                File.WriteAllText(e.Args[1], System.Text.Json.JsonSerializer.Serialize(new { success = false, error = ex.ToString() }));
                Shutdown(1); return;
            }
            MessageBox.Show("Startup failed. Check appsettings.json, the sample files, and the prerequisites.\n" + ex.GetType().Name,
                "OGC demo", MessageBoxButton.OK, MessageBoxImage.Error);
            Shutdown(1);
        }
    }
    protected override void OnExit(ExitEventArgs e)
    {
        Mapsui.Logging.Logger.LogDelegate = null;
        _host?.Dispose(); base.OnExit(e);
    }
}

using System.Windows;

namespace OgcDemo.Wpf;

public partial class MainWindow : Window

    private readonly MainViewModel _viewModel;
    public MainWindow(MainViewModel viewModel)
    {
        InitializeComponent(); _viewModel = viewModel; DataContext = viewModel;
        MapView.Map = viewModel.Map; viewModel.Map.Tapped += MapTapped;
        Closed += (_, _) => { viewModel.Map.Tapped -= MapTapped; viewModel.Dispose(); };

    {

        await _viewModel.SelectAsync(info.Feature, e.ScreenPosition.X, e.ScreenPosition.Y);
    }
}

using System.Windows;

using Mapsui;
using Mapsui.Extensions;

namespace OgcDemo.Wpf;

public partial class MainViewModel : ObservableObject, IDisposable
{

    private readonly ILogger<MainViewModel> _log;
    private readonly List<ConnectedLayer> _connections = [];
    private readonly MemoryLayer _highlight = FeatureLayers.Highlight();
    private readonly LatestRequest _fetch = new();
    private readonly LatestRequest _identify = new();
    private readonly CancellationTokenSource _lifetime = new();
    private bool _disposed;
    public Map Map { get; } = new() { CRS = "EPSG:3857", BackColor = new Mapsui.Styles.Color(239, 244, 248) };

    public MainViewModel(DemoOptions options, ILogger<MainViewModel> log)
    {

    {
        Map.Layers.Add(layer); Map.Layers.MoveToTop(_highlight);
        Layers.Insert(0, new LayerEntry(layer, () => { Map.Refresh(); _ = RefreshWfsAsync(); }));
    }

    private void Move(int delta)
    {
        if (SelectedLayer is not { } selected) return;

        Layers.Move(i, j); Map.Layers.Move(Layers.Count - 1 - j, selected.Layer); Map.Layers.MoveToTop(_highlight); Map.RefreshGraphics();
    }
    [RelayCommand] private void RemoveLayer()

        if (SelectedLayer is not { } selected) return;

# 04 — Navigate and transform coordinates

## Purpose and prerequisites

Learn the difference between geographic coordinates, map coordinates, and screen coordinates. Use the running local demo. No remote service is needed.

GeoJSON positions use longitude then latitude in degrees. The map uses EPSG:3857 in metres. A mouse position uses pixels relative to the map control. Never pass one of these coordinate types where another is expected.

## Step by step

1. Inspect `Demo.InitialExtent`: west, south, east, north, in longitude/latitude degrees.
2. Follow `Coordinates.ProjectExtent`: validate the extent, transform both corners, create a Mapsui `MRect` in map metres.
3. Click Home. `Navigator.ZoomToBox` chooses a resolution that fits the transformed extent.
4. Pan and zoom with the mouse, then use the +/− toolbar buttons. Rotation is locked so WMS identification uses the same unrotated bounding box as the visible image.
5. Read `Coordinates.ToMercator`. It copies geometry and changes every coordinate through an NTS coordinate-sequence filter. Setting `SRID = 3857` alone would only relabel the geometry and is incorrect.
6. Run focused checks:

```powershell
dotnet test tests/OgcDemo.Tests --no-restore --filter "FullyQualifiedName~Projection|FullyQualifiedName~AxisOrder|FullyQualifiedName~InvalidCoordinates"
```

## Axis order

For EPSG:4326, WMS 1.3.0 uses latitude/longitude axis order in BBOX; WMS 1.1.1 uses longitude/latitude. The core WFS 1.1/2.0 path also respects the CRS axis order. The actual remote-layer demo requests EPSG:3857, which keeps x/y ordering consistent. These rules do not change GeoJSON's longitude/latitude order.

The axis-order helper is tested even though service rendering is restricted to 3857. Do not solve axis problems by indiscriminately swapping all coordinates. Check the protocol version, CRS identifier, and encoding first.

Web Mercator excludes the poles and distorts distance and area. The application rejects latitude outside its valid range instead of producing infinities. The core has no measurement tool and does not present Web Mercator area as ground-truth area. Local national grids and dateline-crossing extents require explicit extensions.

## Checkpoint

Round-trip projection checks pass. A feature near longitude 35 degrees has an x coordinate of millions of metres, not 35 metres. Home restores the expected synthetic training area. If data appears far away, inspect source CRS before modifying navigation.

using System.Globalization;
using Mapsui;
using Mapsui.Projections;
using NetTopologySuite.Geometries;

namespace OgcDemo.Core;

public static class Coordinates
{
    public const double MaxLatitude = 85.0511287798066;
    public static MPoint Project(double longitude, double latitude)
    {
        if (!double.IsFinite(longitude) || !double.IsFinite(latitude) || longitude is < -180 or > 180 || Math.Abs(latitude) > MaxLatitude)
            throw new DemoException("Coordinates must be longitude/latitude within Web Mercator's valid range.");
        var (x, y) = SphericalMercator.FromLonLat(longitude, latitude);
        return new MPoint(x, y);
    }
    public static MRect ProjectExtent(double[] bounds)
    {
        if (bounds.Length != 4 || bounds[0] >= bounds[2] || bounds[1] >= bounds[3])
            throw new DemoException("InitialExtent must be [west,south,east,north], without crossing the dateline.");
        var a = Project(bounds[0], bounds[1]); var b = Project(bounds[2], bounds[3]);
        return new MRect(a.X, a.Y, b.X, b.Y);
    }
    public static string Bbox(MRect b, string crs, string protocol, string version)
    {
        var swap = crs == "EPSG:4326" && (protocol == "WFS" || version == "1.3.0");
        double[] values = swap ? [b.MinY, b.MinX, b.MaxY, b.MaxX] : [b.MinX, b.MinY, b.MaxX, b.MaxY];
        return string.Join(",", values.Select(v => v.ToString("R", CultureInfo.InvariantCulture)));
    }
    public static Geometry ToMercator(Geometry input)
    {
        var copy = input.Copy();
        copy.Apply(new ProjectionFilter()); copy.GeometryChanged(); copy.SRID = 3857;
        return copy;
    }
    private sealed class ProjectionFilter : ICoordinateSequenceFilter
    {
        public bool Done => false;
        public bool GeometryChanged => true;
        public void Filter(CoordinateSequence seq, int i)
        {
            var p = Project(seq.GetX(i), seq.GetY(i));
            seq.SetX(i, p.X); seq.SetY(i, p.Y);
        }
    }
}

# 05 — Build graphics overlays and load GeoJSON

## Purpose and prerequisites

Create visible vector data without contacting an OGC service. Complete the coordinate lesson first.

A Mapsui `MemoryLayer` holds `IFeature` instances. `GeometryFeature` wraps NetTopologySuite geometry. A layer style supplies default point, line, and polygon appearance. These are actual vector features; their attributes and geometry remain available after rendering.

## Step by step

1. Read `FeatureLayers.Graphics`. It constructs a point, a line, and a polygon from invented coordinates. It transforms them to 3857 and attaches a human-readable `name` attribute.
2. Click Add graphics. A new memory layer appears at the top of the user-layer list. Use the selected-layer controls to hide or remove it; the bundled source layer remains independent.
3. Open `samples/sites.geojson` in a text editor. Its three features illustrate a point, line, and polygon with a hole. All names and locations are invented training data.
4. Click Open GeoJSON and choose that file. The importer validates limits and geometry, copies attributes, and transforms all coordinates before adding the layer.
5. Click the polygon interior and compare with its hole. A hole is not a separate feature and should remain unfilled.
6. Test the importer:

```powershell
dotnet test tests/OgcDemo.Tests --no-restore --filter "FullyQualifiedName~GeoJson|FullyQualifiedName~Highlight"
```

## Implementation details that matter

The importer accepts a FeatureCollection, not an arbitrary JSON document. The reference uses `NetTopologySuite.IO.GeoJSON4STJ` to avoid hand-parsing nested coordinate arrays. The constructor takes geometry that is already in map coordinates. A shared theme chooses SymbolStyle for points and VectorStyle for lines/polygons. Applying SymbolStyle to every geometry would draw vertex symbols instead of line strokes and polygon fills. Styles are reused rather than allocated for every frame.

The importer rejects a legacy `crs` member because RFC 7946 fixes the coordinate convention. Convert non-4326 source data before loading it. Unsupported or invalid data produces a visible import error without deleting existing layers.

Import and parsing occur asynchronously. There is an 8 MiB and 10,000-feature teaching limit. Large datasets need spatial indexing and viewport loading; do not remove these bounds merely to demonstrate a large file.

## Checkpoint

You can load the sample twice as independent layers, toggle either one, and select a geometry. Removing an imported layer does not change the file on disk. The map remains usable if a later import fails.

## Understand the requests

GetCapabilities describes the service. GetMap returns image pixels, with LAYERS, STYLES, CRS/SRS, BBOX, WIDTH, HEIGHT, and FORMAT. GetFeatureInfo adds QUERY_LAYERS, INFO_FORMAT, and I/J in WMS 1.3.0 or X/Y in 1.1.1. The identifier request must describe the same viewport as the displayed image.

Queryable and supported CRS can be inherited from a parent capabilities layer. The adapter checks that hierarchy. An ordinary `<Exception>` capabilities section advertises response formats; it is not itself a service error. Only an actual exception-report document triggers the service-error path.

A raster identify response does not contain guaranteed geometry. This demo displays text safely; it does not execute returned HTML or invent a vector highlight for a pixel. A local vector hit takes precedence over raster identification.

        var bytes = await transport.GetAsync(OgcTransport.Query(o.Url, ("service", o.Kind), ("request", "GetCapabilities"), ("version", o.Version)), token);

        if (capabilities.Root?.Attribute("version")?.Value != o.Version) throw new DemoException("Service capabilities version differs from configuration.");

            var sources = WmtsCapabilitiesParser.Parse(stream);
            var source = sources.FirstOrDefault(s => s.Schema is WmtsTileSchema w && w.Layer == o.Layer && w.TileMatrixSet == o.MatrixSet && w.Style == o.Style && w.Format == o.Format)
                ?? throw new DemoException("WMTS layer/style/format/matrix-set combination was not advertised.");
            if (!GmlFeatures.IsMercator(source.Schema.Srs)) throw new DemoException("WMTS matrix set must use EPSG:3857.");
            return new ConnectedLayer(o, new TileLayer(new AuthenticatedTileSource(source, transport)) { Name = o.Name }, transport);
        }
        var xml = new XmlDocument { XmlResolver = null }; using (var reader = capabilities.CreateReader()) xml.Load(reader);
        var provider = new WmsProvider(xml, url => transport.GetAsync(url)) { CRS = o.Crs, Transparent = true, ContinueOnError = false };
        provider.AddLayer(o.Layer); if (!string.IsNullOrEmpty(o.Style)) provider.AddStyle(o.Style);
        provider.SetImageFormat(o.Format);
        var advertised = capabilities.Descendants().FirstOrDefault(e => e.Name.LocalName == "Layer" && e.Elements().Any(n => n.Name.LocalName == "Name" && n.Value == o.Layer))
            ?? throw new DemoException("WMS layer was not advertised.");
        var hierarchy = advertised.AncestorsAndSelf().Where(e => e.Name.LocalName == "Layer").ToArray();
        if (!hierarchy.SelectMany(e => e.Elements()).Where(e => e.Name.LocalName is "CRS" or "SRS").Any(e => e.Value.Split(' ').Any(GmlFeatures.IsMercator)))
            throw new DemoException("WMS layer must advertise EPSG:3857.");
        var queryable = hierarchy.Select(e => (string?)e.Attribute("queryable")).FirstOrDefault(v => v != null) is "1" or "true";
        var info = capabilities.Descendants().FirstOrDefault(e => e.Name.LocalName == "GetFeatureInfo");
        var format = info?.Elements().FirstOrDefault(e => e.Name.LocalName == "Format" && e.Value == "text/plain")?.Value
            ?? info?.Elements().FirstOrDefault(e => e.Name.LocalName == "Format" && e.Value.Contains("xml"))?.Value;
        var infoUrl = info?.Descendants().FirstOrDefault(e => e.Name.LocalName == "Get")?.Descendants().FirstOrDefault(e => e.Name.LocalName == "OnlineResource")?.Attributes().FirstOrDefault(a => a.Name.LocalName == "href")?.Value;
        return new ConnectedLayer(o, new ImageLayer(o.Name) { DataSource = provider }, transport)
            { Wms = provider, Queryable = queryable && format != null && infoUrl != null, InfoFormat = format, InfoUrl = infoUrl };
    }
    public static async Task<string> IdentifyAsync(ConnectedLayer layer, MRect extent, int width, int height, int x, int y, CancellationToken token)
    {

        var url = OgcTransport.Query(layer.InfoUrl!, ("service", "WMS"), ("version", o.Version), ("request", "GetFeatureInfo"),
            ("layers", o.Layer), ("query_layers", o.Layer), ("styles", o.Style), ("format", o.Format), ("info_format", layer.InfoFormat!),
            (o.Version == "1.3.0" ? "crs" : "srs", o.Crs), ("bbox", Coordinates.Bbox(extent, o.Crs, "WMS", o.Version)),
            ("width", width.ToString(CultureInfo.InvariantCulture)), ("height", height.ToString(CultureInfo.InvariantCulture)),
            (o.Version == "1.3.0" ? "i" : "x", x.ToString(CultureInfo.InvariantCulture)), (o.Version == "1.3.0" ? "j" : "y", y.ToString(CultureInfo.InvariantCulture)), ("feature_count", "10"));
        var text = Encoding.UTF8.GetString(await layer.Transport.GetAsync(url, token));
        return text.Length > 12000 ? text[..12000] + "\n[Display truncated]" : text;
    }

        : HttpTileSource(source.Schema, source, source.Name, attribution: source.Attribution)

            await transport.GetAsync(source.GetUrl(info).AbsoluteUri, token ?? CancellationToken.None);

## Purpose and prerequisites

## Step by step

2. Rebuild and launch from Windows PowerShell:

3. Choose that profile and connect. The adapter parses capabilities with BruTile and selects a source by **layer + style + format + matrix set**. Human titles are not stable identifiers.

## How tile delivery works

A WMTS matrix defines scale denominator, origin, tile dimensions, matrix width/height, and a matrix identifier. BruTile translates viewport requests into those matrix coordinates and uses the advertised ResourceURL or KVP operation endpoint. This is why the application does not construct a guessed `/z/x/y.png` path.

The source wrapper retains BruTile's URL construction but routes tile bytes through the same bounded, authenticated transport used for capabilities. Authenticating only the capabilities request is insufficient; every protected tile request needs authentication too.

The demo supports 3857 raster matrix sets and rejects other CRSs. It does not reproject cached raster tiles. Persistent caching and disconnected prefetch are extension topics; ordinary in-memory rendering caches are not an offline dataset.

## Checkpoint

Tiles render at multiple scales, align with local vectors, and use the configured style and matrix set. Authentication tests verify both discovery and tile requests. Missing tiles may be outside advertised matrix limits or the data coverage; check capabilities and requested matrix identifiers before changing the origin arithmetic.

# 09 — Retrieve WFS features within the current view

## Purpose and prerequisites

Load server-side vector geometry for selection and attribute inspection. Obtain an internal WFS 1.1.0 or 2.0.0 endpoint offering a qualified feature type, EPSG:3857, and GML 3.1/3.2 output. The service must support HTTP GET for the operations used here.

## Step by step

1. Enable and configure the WFS profile in the private settings. Use the exact type name, including its namespace prefix when advertised. Start with MaxFeatures 1000 and the default response-size bound.
2. Rebuild, launch, and connect as in lesson 07.
3. Observe the initialization requests: GetCapabilities verifies version, type, CRS, and output format; DescribeFeatureType retrieves and checks that an XML schema was returned. The demo does not attempt a general schema-driven feature editor.
4. Pan to the data coverage and wait briefly. After a 300 ms debounce, GetFeature requests the current BBOX in 3857 with `count` (2.0) or `maxFeatures` (1.1).
5. Click a returned vector feature. Its geometry is highlighted and its scalar attributes are displayed, just like a local feature.
6. Pan rapidly. Old requests are canceled, and generation checks prevent late completions from replacing the new viewport data.
7. Run focused tests:

```powershell
dotnet test tests/OgcDemo.Tests --no-restore --filter "FullyQualifiedName~Wfs|FullyQualifiedName~Gml|FullyQualifiedName~OldRequest"
```

## Supported GML and limits

The parser accepts GML 3.1/3.2 `pos` and `posList` with two-dimensional Point, LineString, Polygon (holes included), MultiPoint, MultiLineString/MultiCurve containing lines, and MultiPolygon/MultiSurface containing polygons. It deliberately rejects 3D, curved segments, surface patches, and GML 2 encodings. Only scalar feature properties are copied; complex application schemas need a dedicated adapter.

The response must use the requested EPSG:3857 coordinates. Setting a geometry SRID does not repair a server that returned degrees. An explicit unexpected CRS is rejected. The HTTP payload bound protects parsing, and a server returning more than the requested feature limit is rejected. A result at the cap is labeled as potentially incomplete; zoom in rather than treating it as a complete dataset.

WFS network and XML handling are in a small application adapter. Mapsui/NTS still own the resulting vector layer and rendering. This avoids the fixed transport behavior of the pinned built-in WFS provider while retaining a readable teaching implementation.

## Checkpoint

Features follow the current viewport, are selectable, and obey the configured limits. Hiding/removing a WFS layer does not allow an outstanding response to restore it. Server exceptions and unsupported encodings produce a visible error while existing local layers remain usable.

using System.Globalization;
using System.Xml.Linq;
using Mapsui.Nts;
using NetTopologySuite.Geometries;

namespace OgcDemo.Core;

/// <summary>A deliberately bounded GML 3.1/3.2 reader; not a general GML implementation.</summary>
public static class GmlFeatures
{
    private static readonly GeometryFactory Factory = new(new PrecisionModel(), 3857);
    private static bool IsGml(XElement e) => e.Name.NamespaceName is "http://www.opengis.net/gml" or "http://www.opengis.net/gml/3.2";
    private static readonly string[] GeometryNames = ["Point", "LineString", "Polygon", "MultiPoint", "MultiCurve", "MultiSurface", "MultiLineString", "MultiPolygon"];
    public static IReadOnlyList<GeometryFeature> Read(byte[] bytes, int limit)
    {
        var doc = OgcTransport.ParseXml(bytes);
        if (doc.Root?.Name.LocalName != "FeatureCollection") throw new DemoException("Expected a WFS FeatureCollection.");
        var members = doc.Root.Elements().Where(e => e.Name.LocalName is "member" or "featureMember").SelectMany(e => e.Elements()).ToList();
        members.AddRange(doc.Root.Elements().Where(e => e.Name.LocalName == "featureMembers").SelectMany(e => e.Elements()));
        if (members.Count > limit) throw new DemoException("The WFS ignored the feature limit. Zoom in or configure server limits.");
        return members.Select(f =>
        {
            var geometry = f.Descendants().FirstOrDefault(e => IsGml(e) && GeometryNames.Contains(e.Name.LocalName));
            if (geometry is null) throw new DemoException("WFS geometry is null or unsupported. Use simple 2D GML geometry.");
            foreach (var parent in geometry.Ancestors())
            {
                if (parent.Attribute("srsName") is { } srs && !IsMercator(srs.Value)) throw new DemoException("WFS returned an unexpected inherited CRS.");
                if (parent.Attribute("srsDimension") is { Value: not "2" }) throw new DemoException("The demo accepts only 2D GML coordinates.");
            }
            var parsed = ReadGeometry(geometry);
            if (parsed.IsEmpty || !parsed.IsValid) throw new DemoException("WFS returned empty or invalid geometry.");
            var feature = new GeometryFeature(parsed);
            feature["id"] = f.Attributes().FirstOrDefault(a => a.Name.LocalName is "id" or "fid")?.Value ?? "";
            foreach (var p in f.Elements().Where(e => !e.HasElements)) feature[p.Name.LocalName] = p.Value;
            return feature;
        }).ToArray();
    }
    private static Geometry ReadGeometry(XElement e)
    {
        foreach (var node in e.DescendantsAndSelf())
        {
            var srs = node.Attribute("srsName")?.Value;
            if (srs != null && !IsMercator(srs)) throw new DemoException("WFS returned a CRS other than requested EPSG:3857.");
            if (node.Attribute("srsDimension") is { Value: not "2" }) throw new DemoException("The demo accepts only 2D GML coordinates.");
        }
        return e.Name.LocalName switch
        {
            "Point" => Factory.CreatePoint(ReadCoordinates(e).Single()),
            "LineString" => Factory.CreateLineString(ReadCoordinates(e)),
            "Polygon" => ReadPolygon(e),
            "MultiPoint" => Factory.CreateMultiPoint(e.Descendants().Where(n => IsGml(n) && n.Name.LocalName == "Point").Select(n => (Point)ReadGeometry(n)).ToArray()),
            "MultiCurve" or "MultiLineString" => ReadMultiLine(e),
            "MultiSurface" or "MultiPolygon" => ReadMultiPolygon(e),
            _ => throw new DemoException("Unsupported GML geometry; curves, surfaces, and 3D need a dedicated extension.")
        };
    }
    private static MultiLineString ReadMultiLine(XElement e)
    {
        if (e.Descendants().Any(n => n.Name.LocalName is "Curve" or "Arc")) throw new DemoException("Curved GML geometry is unsupported.");
        return Factory.CreateMultiLineString(e.Descendants().Where(n => IsGml(n) && n.Name.LocalName == "LineString").Select(n => (LineString)ReadGeometry(n)).ToArray());
    }
    private static MultiPolygon ReadMultiPolygon(XElement e)
    {
        if (e.Descendants().Any(n => n.Name.LocalName == "Surface")) throw new DemoException("GML Surface patches are unsupported; request polygons.");
        return Factory.CreateMultiPolygon(e.Descendants().Where(n => IsGml(n) && n.Name.LocalName == "Polygon").Select(n => (Polygon)ReadGeometry(n)).ToArray());
    }
    private static Polygon ReadPolygon(XElement e)
    {
        var outer = e.Elements().FirstOrDefault(n => n.Name.LocalName == "exterior") ?? throw new DemoException("Polygon exterior is missing.");
        var shell = Factory.CreateLinearRing(ReadCoordinates(outer));
        var holes = e.Elements().Where(n => n.Name.LocalName == "interior").Select(n => Factory.CreateLinearRing(ReadCoordinates(n))).ToArray();
        return Factory.CreatePolygon(shell, holes);
    }
    private static Coordinate[] ReadCoordinates(XElement e)
    {
        var elements = e.DescendantsAndSelf().Where(n => IsGml(n) && n.Name.LocalName is "pos" or "posList").ToArray();
        if (elements.Length == 0) throw new DemoException("Expected GML pos or posList coordinates (GML 3.1/3.2).");
        var values = string.Join(" ", elements.Select(n => n.Value)).Split((char[]?)null, StringSplitOptions.RemoveEmptyEntries)
            .Select(v => double.Parse(v, CultureInfo.InvariantCulture)).ToArray();
        if (values.Length % 2 != 0 || values.Any(v => !double.IsFinite(v) || Math.Abs(v) > 20037508.35))
            throw new DemoException("GML contains invalid 2D Web Mercator coordinates.");
        return Enumerable.Range(0, values.Length / 2).Select(i => new Coordinate(values[i*2], values[i*2+1])).ToArray();
    }
    public static bool IsMercator(string text) => text.Equals("EPSG:3857", StringComparison.OrdinalIgnoreCase) ||
        text.Equals("urn:ogc:def:crs:EPSG::3857", StringComparison.OrdinalIgnoreCase) ||
        text.Equals("http://www.opengis.net/def/crs/EPSG/0/3857", StringComparison.OrdinalIgnoreCase);
}

# 10 — Authenticate, diagnose failures, and tune performance

## Purpose and prerequisites

Connect to protected internal services while preserving responsive behavior and useful diagnostics. You need the service's normal access permissions; this tutorial does not provision accounts or change server security.

## Step by step (Windows PowerShell)

1. Set `Authentication` to `Basic` and select a credential prefix in the private settings. Basic authentication requires HTTPS. Leave it as Anonymous when credentials are unnecessary.
2. Obtain credentials through a prompt instead of placing a password in command history:

```powershell
$ogcCredential = Get-Credential
$env:OGC_DEMO_USERNAME = $ogcCredential.UserName
$env:OGC_DEMO_PASSWORD = $ogcCredential.GetNetworkCredential().Password
dotnet run --project src/OgcDemo.Wpf --no-build --no-restore
Remove-Item Env:OGC_DEMO_USERNAME, Env:OGC_DEMO_PASSWORD
$ogcCredential = $null
```

This uses environment variables for a small demo, not a production credential vault. The variables must exist in the process that launches the application. Do not print them or export them into a tutorial bundle.

3. Connect, pan, identify WMS, and retrieve WFS features. All discovery and follow-up requests use the same transport policy.
4. Test an unavailable service or an incorrect profile. The status bar should show the failure without closing the local demo.
5. Run failure tests:

```powershell
dotnet test tests/OgcDemo.Tests --no-restore --filter "FullyQualifiedName~Failure|FullyQualifiedName~Unauthorized|FullyQualifiedName~Cancellation|FullyQualifiedName~Authentication"
```

## Troubleshooting

| Symptom | First checks |
|---|---|
| Restore fails | Correct internal v3 feed, feed access, required package/version present, lock hash |
| Startup fails | .NET Desktop Runtime/SDK, full published folder, valid JSON, samples present |
| HTTP 401/403 | Correct prefix variables, user permissions, advertised operation endpoint |
| TLS failure | Trusted enterprise CA and correct server name; do not disable validation |
| Different-origin error | Capabilities advertise another scheme/host/port; use an approved same-origin gateway |
| Empty WMS | Layer/style spelling, supported CRS, coverage, transparency, image format |
| Wrong placement | Source CRS, 4326 axis order, protocol version, not just the declared SRID |
| WMTS missing | Exact layer/style/matrix combination and matrix coverage |
| WFS unsupported | Advertised output format, GML encoding, dimension, geometry subset |
| Feature limit reached | Zoom in; the view is incomplete, not a full export |
| Freeze or excess requests | Look for UI-thread blocking, removed debounce, or repeated connection attempts |

## Performance decisions

Keep payload/feature limits; retrieve WFS by viewport. Do not load a whole enterprise dataset just to display one town. Keep shared styles, use WMTS when the server offers suitable tiles, and avoid unnecessary layer refreshes. For larger vectors, introduce spatial indexing and simplification with accuracy tests. Measure request time, response size, feature count, and UI responsiveness separately; this demo does not claim a throughput benchmark.

Each connection has a whole-request timeout and byte limit. Redirects are rejected, certificates are normally validated, XML DTDs are prohibited, and Basic credentials are confined to the configured origin. Safe log messages describe operation and exception type without echoing arbitrary server text.

## Checkpoint

Authentication reaches both capabilities and data requests. Failure tests pass, the log does not contain the synthetic secret payload, and an unavailable service leaves local layers usable. Air-gapped means no internet access; it does not mean internal OGC services are unavailable.

        _client = new HttpClient(testHandler ?? new HttpClientHandler { AllowAutoRedirect = false })
        { Timeout = TimeSpan.FromSeconds(options.TimeoutSeconds) };
        _client.DefaultRequestHeaders.UserAgent.ParseAdd("OgcDemo/1.0");
        if (options.Authentication == "Basic")
        {
            var user = Environment.GetEnvironmentVariable(options.CredentialPrefix + "_USERNAME");
            var password = Environment.GetEnvironmentVariable(options.CredentialPrefix + "_PASSWORD");
            if (string.IsNullOrEmpty(user) || password is null || user.Contains(':'))
                throw new DemoException("Set the configured credential-prefix _USERNAME and _PASSWORD environment variables.");
            _client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Basic", Convert.ToBase64String(Encoding.UTF8.GetBytes(user + ":" + password)));
        }
    }
    public async Task<byte[]> GetAsync(string url, CancellationToken token = default)
    {
        var target = new Uri(url);
        // Capabilities can advertise other endpoints. Do not forward credentials to a different origin.
        if (target.Scheme != _origin.Scheme || target.Host != _origin.Host || target.Port != _origin.Port || target.UserInfo.Length != 0)
            throw new DemoException("An advertised endpoint has a different origin. Configure a same-origin service gateway.");
        using var deadline = CancellationTokenSource.CreateLinkedTokenSource(token);
        deadline.CancelAfter(TimeSpan.FromSeconds(_options.TimeoutSeconds));
        var requestToken = deadline.Token;
        try
        {
            using var response = await _client.GetAsync(target, HttpCompletionOption.ResponseHeadersRead, requestToken).ConfigureAwait(false);
            if (!response.IsSuccessStatusCode)
                throw new DemoException($"OGC HTTP {(int)response.StatusCode}. Check endpoint, permissions, and credentials.");
            if (response.Content.Headers.ContentLength > _options.MaxResponseBytes)
                throw new DemoException("Response exceeds MaxResponseBytes. Zoom in or raise the configured limit.");
            using var input = await response.Content.ReadAsStreamAsync(requestToken).ConfigureAwait(false);
            using var output = new MemoryStream(); var buffer = new byte[16384]; int read;
            while ((read = await input.ReadAsync(buffer, requestToken).ConfigureAwait(false)) > 0)
            {
                if (output.Length + read > _options.MaxResponseBytes) throw new DemoException("Response exceeds MaxResponseBytes.");
                output.Write(buffer, 0, read);
            }
            var bytes = output.ToArray();
            if (response.Content.Headers.ContentType?.MediaType?.Contains("xml", StringComparison.OrdinalIgnoreCase) == true ||
                bytes.AsSpan().TrimStart((byte)' ').StartsWith("<"u8))
            {
                var xml = ParseXml(bytes);
                if (xml.Root?.Name.LocalName is "ExceptionReport" or "ServiceExceptionReport" or "ServiceException")
                    throw new DemoException("OGC service exception. Check capabilities, layer name, CRS, format, and permissions.");
            }
            return bytes;
        }
        catch (OperationCanceledException) when (!token.IsCancellationRequested) { throw new DemoException("OGC request timed out."); }
        catch (HttpRequestException) { throw new DemoException("OGC connection failed. Check network access and the trusted certificate chain."); }
    }
    public static XDocument ParseXml(byte[] bytes)
    {
        try
        {
            using var stream = new MemoryStream(bytes);
            using var reader = XmlReader.Create(stream, new XmlReaderSettings { DtdProcessing = DtdProcessing.Prohibit, XmlResolver = null, MaxCharactersInDocument = 33554432 });
            return XDocument.Load(reader);
        }
        catch (XmlException) { throw new DemoException("The service returned malformed or unsupported XML."); }
    }
    public static string Query(string url, params (string Key, string Value)[] parameters)
    {
        var builder = new UriBuilder(url);
        var values = new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase);
        foreach (var pair in builder.Query.TrimStart('?').Split('&', StringSplitOptions.RemoveEmptyEntries))
        {
            var kv = pair.Split('=', 2); values[Uri.UnescapeDataString(kv[0])] = kv.Length == 2 ? Uri.UnescapeDataString(kv[1]) : "";
        }
        foreach (var (key, value) in parameters) values[key] = value;
        builder.Query = string.Join("&", values.Select(p => Uri.EscapeDataString(p.Key) + "=" + Uri.EscapeDataString(p.Value)));
        return builder.Uri.AbsoluteUri;
    }
    public void Dispose() => _client.Dispose();
}

# Configuration contract

## Package feed

`NuGet.Config` clears inherited feeds and declares one placeholder Artifactory NuGet v3 endpoint. Copy it to ignored `NuGet.local.Config`, replace that endpoint, and pass `--configfile NuGet.local.Config` on restore. Keep `<clear />`. There is no public fallback. Package hashes and resolved versions are in committed `packages.lock.json` files.

Use your organization's credential provider or `NuGetPackageSourceCredentials_Artifactory` environment variable if the feed requires authentication. Do not put secrets into the template. NuGet's credential variable uses `Username=...;Password=...` and, when required by the feed, `ValidAuthenticationTypes=Basic`. Obtain credentials through your organization's normal procedure. Internal OGC credentials and Artifactory credentials are separate.

## Application settings

Copy the **whole** `src/OgcDemo.Wpf/appsettings.json` to `src/OgcDemo.Wpf/appsettings.local.json` before editing. JSON configuration arrays merge by numeric index; a short replacement Services array does not delete remaining base entries. Keep unused entries disabled. Restart after edits; configuration is read at startup.

| Setting | Meaning / default |
|---|---|
| Demo.InitialExtent | `[west,south,east,north]` in degrees; no dateline crossing |
| Services[].Name | Human-readable tree/selector label |
| Kind | Exactly `WMS`, `WMTS`, or `WFS` |
| Enabled | Exposes the profile in the selector; does not auto-connect |
| Url | Absolute HTTPS OGC endpoint, without username/password |
| Version | WMS 1.1.1/1.3.0; WMTS 1.0.0; WFS 1.1.0/2.0.0 |
| Layer | Advertised layer identifier or qualified WFS type name, case-sensitive |
| Style | WMS style (empty means default); exact advertised WMTS style |
| Crs | `EPSG:3857`; other service display CRSs are outside the core |
| MatrixSet | Exact WMTS matrix-set identifier, not a guessed zoom-level label |
| Format | WMS/WMTS advertised image type, normally `image/png`; WFS discovers GML output |
| Authentication | `Anonymous` or `Basic` |
| CredentialPrefix | Environment variable prefix, default `OGC_DEMO` |
| TimeoutSeconds | Whole-request deadline, 1–120; default 20 |
| MaxFeatures | WFS per-request cap, 1–10,000; default 1,000 |
| MaxResponseBytes | Per-response bound, 1 KiB–32 MiB; default 8 MiB |

Set `OGC_DEMO_USERNAME` and `OGC_DEMO_PASSWORD` only when using Basic with that prefix. The app reads them from its process environment. Do not enter passwords in commands saved to shell history; use an interactive credential prompt and assign its values to environment variables in the launching session. Clear those variables after the application exits.

Capabilities may advertise request endpoints different from the capabilities URL. The demo accepts a different path on the same scheme, host, and port; it rejects a different origin and HTTP redirects. Ask for a same-origin gateway if your deployment advertises multiple origins. It never forwards Basic credentials to an unapproved host.

## Data and scope limits

GeoJSON: FeatureCollection, RFC 7946 longitude/latitude, no legacy `crs` member, valid nonempty geometry, at most 8 MiB and 10,000 features. Latitude must be within approximately ±85.0511 degrees for Web Mercator.

WFS: HTTP GET, GML 3.1/3.2, 2D Point/LineString/Polygon (including holes), MultiPoint, MultiLineString/MultiCurve containing lines, and MultiPolygon/MultiSurface containing polygons. Curved segments, surface patches, complex nested attributes, remote XLinks, GML 2 `coordinates`, and 3D are unsupported. Only scalar feature properties are displayed. A layer at the feature cap is explicitly marked incomplete; the core does not silently paginate or claim complete coverage.

Logs: `%LOCALAPPDATA%\OgcDemo\logs\ogc-demo-YYYYMMDD.log`, UTC timestamps. Daily filenames are rotation, not retention; see the deployment lesson. The logger omits exception payloads; callers must still use authored messages, never sensitive state.

# Advanced extension lessons

These are extension designs and exercises. They are deliberately **not implemented** by the core demo. Finish the working OGC/local-feature lessons first. Each extension has a concrete integration point and an acceptance test so a human or local model can continue without confusing proposed behavior with existing functionality.

## SQLite — persist user preferences

**Goal:** restore user-created layer profiles and visibility/order after restarting. Start with ordinary application tables, not spatial storage.

1. Add a pinned SQLite provider available in Artifactory to a separate persistence project. Keep native runtime assets explicit for win-x64.
2. Introduce an `ILayerProfileStore` with asynchronous load/save operations. Store profile identifiers, display settings, and a schema version; exclude passwords and access tokens.
3. Use parameterized SQL, transactions for a whole workspace save, and a migration table. Place the database under `%LOCALAPPDATA%\OgcDemo`, never beside a read-only installed EXE.
4. Load persisted settings at startup before adding layers. Save only explicit user settings, not transient highlights or all fetched WFS data.
5. Test first launch, restart, interrupted writes, schema migration, and a read-only directory. A corrupt store must not prevent the bundled local demo from starting.

## GeoPackage — read an offline vector dataset

**Goal:** load a selected GeoPackage feature table by viewport. A `.gpkg` is a SQLite container with spatial metadata and geometry encoding; it is not equivalent to an arbitrary table of WKB.

1. Select a vetted provider that understands GeoPackage metadata, geometry headers, and spatial indexes. Verify its support on the chosen .NET/Windows versions before adding it.
2. Read `gpkg_contents`, geometry-column metadata, source CRS, and bounds. Reject a table with an unknown CRS rather than assuming 4326.
3. Add a data-source adapter returning `GeometryFeature` objects in the map CRS. Use a spatial index and a bounded query for the current extent.
4. Keep tiles and vector tables as separate capabilities; a provider supporting vector tables does not necessarily support GeoPackage raster tiles.
5. Test multiple geometry types, polygon holes, empty/null geometry, missing indexes, multiple tables, and a non-4326 dataset. Compare transformed control points with a trusted GIS tool.

For small teaching inputs, converting a selected table to RFC 7946 GeoJSON through an approved conversion tool is a simpler first exercise. Do not claim native GeoPackage support merely because an export can be loaded.

## GDAL — controlled preprocessing

**Goal:** prepare large or unfamiliar source formats outside the UI rendering loop.

1. Use the organization's approved GDAL distribution. Keep its executables, native libraries, PROJ data, and driver versions together. Verify `ogrinfo --version` and the relevant driver's availability.
2. Inspect a source layer and its CRS before converting. Example commands below are **GDAL shell commands**, not application features:

```powershell
ogrinfo -so -al source.gpkg
ogr2ogr -f GeoJSON -t_srs EPSG:4326 -lco RFC7946=YES training-export.geojson source.gpkg selected_table
```

Use a new destination filename. Inspect feature count, bounds, and representative geometries before importing into the demo.

3. If later integrating conversion into the app, execute a configured tool path with `ProcessStartInfo.ArgumentList`; do not concatenate untrusted filenames into a shell command.
4. Run conversion off the dispatcher, capture bounded diagnostic output, allow cancellation, and preserve the original source.
5. Test filenames with spaces, invalid CRS, missing projection grids, unavailable drivers, cancellation, and nonzero exit codes. Log operation results without recording sensitive paths or features.

## Persistent offline cache — separate network isolation from disconnection

**Goal:** allow a deliberately prepared map area to remain available when internal services are unreachable.

1. Define user-selected area, scales, layers, storage limit, expiry, and whether the service permits caching. Air-gapped access to an internal server does not require prefetching by itself.
2. Start with a WMTS tile cache; include service/profile identity, layer, style, format, matrix-set identifier, matrix level, row/column, and authorization scope in the cache key.
3. Store a manifest with extent, CRS, creation time, provenance, and completeness. Never show a partial package as a complete offline map.
4. Separate authenticated users' caches. Credentials are never cache keys or stored payload metadata. Define invalidation and deletion behavior explicitly.
5. Add explicit online/offline mode and a visible missing-data indication. Bound disk use and concurrent downloads; do not launch an unbounded tile crawl.
6. Test disconnected restart, missing tiles, expired entries, changed styles, user changes, interrupted prefetch, and full disk. Check both rendered coverage and manifest counts.

WFS snapshots need their own data-version and edit-conflict policies. WMS viewport-image caching is not interchangeable with WMTS tile caching.

## Search — visible-data search first

**Goal:** find features by their displayed attributes and navigate to them.

1. Add an `IFeatureSearch` interface and a local implementation over loaded vector features. Return a stable feature reference, layer identity, label, and extent.
2. Clearly label the first implementation "Search loaded features"; a bounded WFS viewport is not a complete catalog.
3. Keep filtering and result limits explicit. For server search, discover supported filters and use standard OGC Filter Encoding rather than assuming GeoServer CQL support.
4. Debounce input, cancel previous requests, and reuse the generation-check pattern. Do not block typing on network work.
5. Test duplicate labels, missing attributes, Unicode text, empty results, stale requests, and selecting a result whose layer was removed.

## Editing — local geometry before remote transactions

**Goal:** edit a local copy with undo/redo, validation, and explicit save.

1. Keep selection, editing, and persisted source geometry separate. Begin with adding/moving points; extend to lines/polygons only after undo is reliable.
2. Define commands containing old/new geometry, stable feature identity, and layer identity. Reproject at input/output boundaries.
3. Validate topology before committing edits. Invalid polygon rings must not silently reach the data store.
4. Save a new local GeoJSON file with confirmed destination semantics before attempting server writes. The core demo currently never writes back to an input dataset.
5. Add WFS-T only when the service advertises it and a separate explicit authorization/conflict design exists. Reading WFS does not imply write access.
6. Test undo/redo, canceled edits, invalid geometry, lost selection, save failure, concurrent modification, and CRS round trips.

## Enterprise server integration and deployment

The generic client contract is capabilities plus data requests. Ask the provider's administrator for advertised CRS/format support, layer permissions, bounded WFS access, correct externally advertised operation URLs, and reliable HTTPS. GeoServer can satisfy this contract, but the client does not need its REST API, configuration files, or a PostGIS account.

Production extensions include Windows Integrated Authentication or OAuth, enterprise proxy handling, credential-vault integration, signed packaging, automated update policy, log retention, and accessibility/scaling testing. Implement each against the actual organization's contract and validate it separately. Do not add server provisioning to this client tutorial.

1. Add a pinned SQLite provider available in Artifactory to a separate persistence project. Keep native runtime assets explicit for win-x64.
2. Introduce an `ILayerProfileStore` with asynchronous load/save operations. Store profile identifiers, display settings, and a schema version; exclude passwords and access tokens.
3. Use parameterized SQL, transactions for a whole workspace save, and a migration table. Place the database under `%LOCALAPPDATA%\OgcDemo`, never beside a read-only installed EXE.
4. Load persisted settings at startup before adding layers. Save only explicit user settings, not transient highlights or all fetched WFS data.
5. Test first launch, restart, interrupted writes, schema migration, and a read-only directory. A corrupt store must not prevent the bundled local demo from starting.

## GeoPackage — read an offline vector dataset

**Goal:** load a selected GeoPackage feature table by viewport. A `.gpkg` is a SQLite container with spatial metadata and geometry encoding; it is not equivalent to an arbitrary table of WKB.

1. Select a vetted provider that understands GeoPackage metadata, geometry headers, and spatial indexes. Verify its support on the chosen .NET/Windows versions before adding it.
2. Read `gpkg_contents`, geometry-column metadata, source CRS, and bounds. Reject a table with an unknown CRS rather than assuming 4326.
3. Add a data-source adapter returning `GeometryFeature` objects in the map CRS. Use a spatial index and a bounded query for the current extent.
4. Keep tiles and vector tables as separate capabilities; a provider supporting vector tables does not necessarily support GeoPackage raster tiles.
5. Test multiple geometry types, polygon holes, empty/null geometry, missing indexes, multiple tables, and a non-4326 dataset. Compare transformed control points with a trusted GIS tool.

For small teaching inputs, converting a selected table to RFC 7946 GeoJSON through an approved conversion tool is a simpler first exercise. Do not claim native GeoPackage support merely because an export can be loaded.

## GDAL — controlled preprocessing

**Goal:** prepare large or unfamiliar source formats outside the UI rendering loop.

1. Use the organization's approved GDAL distribution. Keep its executables, native libraries, PROJ data, and driver versions together. Verify `ogrinfo --version` and the relevant driver's availability.
2. Inspect a source layer and its CRS before converting. Example commands below are **GDAL shell commands**, not application features:

```powershell
ogrinfo -so -al source.gpkg
ogr2ogr -f GeoJSON -t_srs EPSG:4326 -lco RFC7946=YES training-export.geojson source.gpkg selected_table
```

Use a new destination filename. Inspect feature count, bounds, and representative geometries before importing into the demo.

3. If later integrating conversion into the app, execute a configured tool path with `ProcessStartInfo.ArgumentList`; do not concatenate untrusted filenames into a shell command.
4. Run conversion off the dispatcher, capture bounded diagnostic output, allow cancellation, and preserve the original source.
5. Test filenames with spaces, invalid CRS, missing projection grids, unavailable drivers, cancellation, and nonzero exit codes. Log operation results without recording sensitive paths or features.

## Persistent offline cache — separate network isolation from disconnection

**Goal:** allow a deliberately prepared map area to remain available when internal services are unreachable.

1. Define user-selected area, scales, layers, storage limit, expiry, and whether the service permits caching. Air-gapped access to an internal server does not require prefetching by itself.
2. Start with a WMTS tile cache; include service/profile identity, layer, style, format, matrix-set identifier, matrix level, row/column, and authorization scope in the cache key.
3. Store a manifest with extent, CRS, creation time, provenance, and completeness. Never show a partial package as a complete offline map.
4. Separate authenticated users' caches. Credentials are never cache keys or stored payload metadata. Define invalidation and deletion behavior explicitly.
5. Add explicit online/offline mode and a visible missing-data indication. Bound disk use and concurrent downloads; do not launch an unbounded tile crawl.
6. Test disconnected restart, missing tiles, expired entries, changed styles, user changes, interrupted prefetch, and full disk. Check both rendered coverage and manifest counts.

WFS snapshots need their own data-version and edit-conflict policies. WMS viewport-image caching is not interchangeable with WMTS tile caching.

## Search — visible-data search first

**Goal:** find features by their displayed attributes and navigate to them.

1. Add an `IFeatureSearch` interface and a local implementation over loaded vector features. Return a stable feature reference, layer identity, label, and extent.
2. Clearly label the first implementation "Search loaded features"; a bounded WFS viewport is not a complete catalog.
3. Keep filtering and result limits explicit. For server search, discover supported filters and use standard OGC Filter Encoding rather than assuming GeoServer CQL support.
4. Debounce input, cancel previous requests, and reuse the generation-check pattern. Do not block typing on network work.
5. Test duplicate labels, missing attributes, Unicode text, empty results, stale requests, and selecting a result whose layer was removed.

## Editing — local geometry before remote transactions

**Goal:** edit a local copy with undo/redo, validation, and explicit save.

1. Keep selection, editing, and persisted source geometry separate. Begin with adding/moving points; extend to lines/polygons only after undo is reliable.
2. Define commands containing old/new geometry, stable feature identity, and layer identity. Reproject at input/output boundaries.
3. Validate topology before committing edits. Invalid polygon rings must not silently reach the data store.
4. Save a new local GeoJSON file with confirmed destination semantics before attempting server writes. The core demo currently never writes back to an input dataset.
5. Add WFS-T only when the service advertises it and a separate explicit authorization/conflict design exists. Reading WFS does not imply write access.
6. Test undo/redo, canceled edits, invalid geometry, lost selection, save failure, concurrent modification, and CRS round trips.

## Enterprise server integration and deployment

The generic client contract is capabilities plus data requests. Ask the provider's administrator for advertised CRS/format support, layer permissions, bounded WFS access, correct externally advertised operation URLs, and reliable HTTPS. GeoServer can satisfy this contract, but the client does not need its REST API, configuration files, or a PostGIS account.

Production extensions include Windows Integrated Authentication or OAuth, enterprise proxy handling, credential-vault integration, signed packaging, automated update policy, log retention, and accessibility/scaling testing. Implement each against the actual organization's contract and validate it separately. Do not add server provisioning to this client tutorial.

## Axis order
